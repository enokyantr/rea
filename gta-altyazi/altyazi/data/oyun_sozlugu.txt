# Genel oyun terimleri sözlüğü (İngilizce = Türkçe)
#
# Amaç: Aksiyon, RPG, nişancı ve açık dünya oyunlarının altyazılarında geçen yerleşik oyun
# terimlerinin Türk oyuncuların alıştığı karşılıklarla ve her satırda aynı biçimde çevrilmesi.
#
# Nasıl çalışır:
# - Her satır:  İngilizce terim = Türkçe karşılık. "#" ile başlayan satırlar yorumdur.
# - Bir terim yalnızca çevrilen altyazı satırında o terim (tam kelime/ifade olarak) geçtiğinde
#   uygulanır; geçmeyen terimlerin çeviriye etkisi yoktur.
# - Kullanıcının kendi sozluk.txt dosyasındaki aynı terim buradaki karşılığın önüne geçer.
#   Bir karşılığı beğenmezseniz sozluk.txt'ye kendi satırınızı yazmanız yeterlidir.
# - Gündelik konuşmada birden çok anlamı olan tek kelimeler (ör. "level", "boss", "drop",
#   "kill", "map", "run", "score", "health", "lobby", "reload", "dodge", "overtime") bilerek
#   eklenmedi; bunlar yalnızca anlamı netleştiren kalıpların içinde yer alır.
# - "HP" (beygir gücü), "MP" (askerî inzibat), "OP" (operasyon), "AI" bilerek eklenmedi:
#   diyalogda oyun dışı anlamlarıyla da sık geçer.
# - Türk oyuncuların İngilizcesiyle kullandığı kısaltmalar ve kalıplar (DLC, XP, NPC, PvP, HUD,
#   "boss" içeren ifadeler, "co-op", "battle royale") olduğu gibi bırakıldı.
# - Hakaret/argo karşılıkları bu dosyada yoktur.
#
# Kaynaklar ve lisanslar:
# - SuperTuxKart Türkçe çevirisi (data/po/tr.po), GPL-3.0-or-later:
#   https://github.com/supertuxkart/stk-code/blob/master/data/po/tr.po
#   Karşılaştırma için kullanıldı. Şu karşılıklar bu çeviriyle aynıdır: multiplayer = çok oyunculu,
#   capture the flag = bayrağı yakala, friend request = arkadaşlık isteği.
# - Luanti (eski adıyla Minetest) Türkçe çevirisi (po/tr/luanti.po), LGPL-2.1-or-later:
#   https://github.com/luanti-org/luanti/blob/master/po/tr/luanti.po
#   Karşılaştırma için kullanıldı. Şu karşılıklar bu çeviriyle aynıdır: inventory = envanter,
#   single-player = tek oyunculu, minimap = mini harita, mouse sensitivity = fare hassasiyeti,
#   game paused = oyun duraklatıldı, join game = oyuna katıl.
# - Xonotic Türkçe çevirisi (common.tr.po), GPL-3.0-or-later:
#   https://github.com/xonotic/xonotic-data.pk3dir/blob/master/common.tr.po
#   Karşılaştırma için kullanıldı. Şu karşılıklar bu çeviriyle aynıdır: checkpoint = kontrol
#   noktası, friendly fire = dost ateşi, out of ammo = cephane kalmadı, sudden death = ani ölüm,
#   kill-death ratio = öldürme-ölme oranı, warmup round = ısınma turu (Xonotic: "ısınma").
# - Battle for Wesnoth Türkçe çevirisi (po/wesnoth/tr.po), GPL-2.0-or-later:
#   https://github.com/wesnoth/wesnoth/blob/master/po/wesnoth/tr.po
#   Karşılaştırma için kullanıldı. Aynı olan karşılık: game over = oyun bitti.
# - Yukarıdaki dört projenin dosyalarından toplu kopyalama yapılmadı; yalnızca yukarıda sayılan
#   kısa ve yaygın terim eşleşmeleri kaynak gösterilerek alındı. Diğer bütün satırlar bu dosya
#   için ayrıca derlendi.
# - Mobidictum "Oyuncular İçin Terimler Sözlüğü" ve "Oyun sektörü terimleri ve kısaltmaları
#   sözlüğü" (lisans belirtilmemiş, tüm hakları saklı varsayıldı):
#   https://mobidictum.com/tr/oyun-sektoru-terimleri-ve-kisaltmalari-sozlugu/
#   Yalnızca yaygın kullanımı doğrulamak için bakıldı (cooldown, loot = ganimet); içerik kopyalanmadı.
# - Microsoft Terminology Collection / Microsoft Language Portal (Microsoft kullanım koşulları):
#   https://learn.microsoft.com/en-us/globalization/reference/microsoft-terminology
#   Kısıtlayıcı koşullar nedeniyle hiçbir terim kopyalanmadı.
# - Ticari oyunların Türkçe yerelleştirmeleri (Steam arayüzü, Riot, Epic, Mojang vb.) telifli
#   olduğundan kopyalanmadı; yalnızca yerleşik terim tercihleri (ör. başarım, dereceli maç,
